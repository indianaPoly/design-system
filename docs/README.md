# 로컬 프리뷰 안내

이 폴더는 디자인 시스템의 색상 토큰 및 컴포넌트를 로컬에서 확인하기 위한 프리뷰 페이지입니다.

## 실행 방법

```bash
bun install
bun run docs:dev -- --host 0.0.0.0 --port 4173
```

브라우저에서 `http://localhost:4173`로 접속하면 프리뷰 페이지가 열립니다.

## 성능 고려사항

프리뷰는 모든 컴포넌트를 한 번에 렌더링하지 않고, 선택된 컴포넌트만 DOM에 마운트합니다.
이를 통해 로컬 데모에서도 DOM 규모를 줄여 빠르게 확인할 수 있도록 구성했습니다.

추가로 다음과 같은 지표를 함께 확인하면 성능 변화를 빠르게 파악할 수 있습니다.

- 번들 크기: `dist` 산출물 크기 확인
- 초기 렌더링 시간: 프리뷰 진입 시 주요 컴포넌트 로딩 시간 측정
- 상호작용 응답성: 버튼/입력 요소 클릭 시 체감 반응 속도 체크
