Input

Inputs allow users to enter and edit text.

Usage

HTML 
<ds-input label="Label" placeholder="Placeholder"></ds-input>

<ds-input 
  label="With Helper" 
  helper="This is a helper text"
></ds-input>

<ds-input 
  label="With Error" 
  error="This field is required" 
  value="Invalid value"
></ds-input>

<ds-input label="Disabled" disabled value="Disabled value"></ds-input>

Properties

Property Type Default
label string ''
helper string ''
error string ''
disabled boolean false
