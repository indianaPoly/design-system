구린 프리뷰를 넘어,
바로 붙여 넣는 제품 UI로.

Lit 기반 디자인 시스템을 shadcn/ui처럼 “좋은 기본값 + 복붙 가능한 블록” 중심으로 정리했습니다. 토큰, 컴포넌트, 예제 코드가 한 화면에서 같이 검증됩니다.

Get Started GitHub

Principles

Beautiful defaults

토큰만 import해도 버튼, 카드, 폼이 같은 제품에서 나온 것처럼 보입니다.

Copy ownership

예제는 Web Component markup 그대로 복사해서 앱 코드에 붙일 수 있게 구성합니다.

State clarity

focus, error, disabled, success/warning/danger가 색과 구조로 동시에 읽힙니다.

Component Showcase

디자인 시스템이 제공하는 주요 컴포넌트들을 확인해보세요. 각 항목은 실제 제품에서 사용되는 룩앤필을 그대로 보여줍니다.

Primary Secondary
